# DashEvo

Dashboard de monitoramento e análise para o Evolution API.

## Sobre o Projeto

Este é um dashboard desenvolvido para monitorar e analisar dados da API Evolution, focado em mensagens, contatos e métricas de chat do WhatsApp.

## Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

## Funcionalidades

- Dashboard de métricas
- Monitoramento de mensagens
- Gestão de contatos
- Interface de chat
- Visualização de métricas

## Instalação

```bash
# Instalar dependências
npm install

# Iniciar o servidor de desenvolvimento
npm run dev
```

## Variáveis de Ambiente

Crie um arquivo `.env.local` na raiz do projeto com as seguintes variáveis:

```
# Configurações da aplicação
EVOLUTION_API_URL=sua_url_da_api_evolution
DATABASE_URL=sua_url_do_banco_de_dados
```
